# Security and Privacy Rules for This Portfolio

Before committing anything to a public repository:

- Never upload passwords, tokens, API keys, recovery keys, private keys, or `.env` files.
- Do not publish real client/employer logs, private console screenshots, tenant IDs, endpoint IDs, internal hostnames, or unapproved data.
- Redact usernames, email addresses, and network identifiers unless they are fictional or clearly safe to share.
- Use only your own systems or systems for which you have explicit authorization.
- Do not upload malware, live phishing attachments, or sensitive packet captures. Describe the analysis and use safe, sanitized evidence instead.
- Do not invent findings, screenshots, tool use, certifications, client work, or production experience.
- Label incomplete projects as **In progress** and explain failed or inconclusive validation honestly.
- Review every file and screenshot before publishing.
